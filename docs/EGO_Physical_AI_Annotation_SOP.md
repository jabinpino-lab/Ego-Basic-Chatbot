# Standard Operating Procedures (SOP): Physical AI Video Annotation & Labeling

## 1. Project Overview & Scope

This document defines the standard operating instructions for egocentric (first-person) video clipping, text captioning, and attribute labeling for Physical AI training dataset creation.

### Key Principles

- **Computer-Generated Keypoints:** 3D hand pose keypoints (`point_3d`) are automatically detected and generated by computer models. **Annotators do not edit, create, or adjust keypoints.**
- **Core Task:** Your primary responsibility is defining accurate temporal bounds (Clip Exports & Sub-goals), tagging required segment attributes, and writing clear text descriptions.
- **Target Audience:** This document is fully self-contained. All rules apply directly as written.
- **What is a good clip and caption? Does the verb and the object annotated in the clip match with what is happening in those frames? (Clips do not have to be frame perfect, as long as the description matches what happens in the video is correct)**

## 2. Timeline Segment Definitions

| **Segment Label** | **Description** | **Max Duration** | **Key Rules** |
| --- | --- | --- | --- |
| **Clip Export** | The complete continuous sequence where the participant performs actions to achieve the main task goal. | **300 seconds** | Tasks longer than 300 seconds must be split by half (need to be aligned with sub-goal clipping), logical segments (e.g., an 8-min task = two 4-min segments). |
| **Sub-goal** | A single action step or small group of micro-actions contributing to the overall task. | **9.99 seconds** | Must strictly be under 10.00 seconds (9.99s maximum). Minimum duration is 1.00s |

## 3. Bounding & Clipping Guidelines

### Sub-goal Bounding Rules

- **Start Frame:** The exact frame where the body or hand begins moving toward the target object/action.
- **End Frame:** The frame where physical contact is broken (hand-object or object-object disengagement).
- **Pouring Exception:** Starts when the container begins to tilt to initiate the pour; ends when liquid stops flowing and the container returns upright.
- **Tolerance:** Bounding within **5 frames** of exact contact or release is acceptable.

### Segment Splitting & Merging

#### Splitting Long Actions

- Continuous physical actions running longer than 9.99s must be split into shorter sub-goal segments under 10 seconds.

#### Merging Actions (Max 3 Micro-actions)

- Up to **3 micro-actions** may be combined into a single Sub-goal **ONLY IF** they are quick, consecutive micro-actions occurring within a total time of 9.99 seconds.
- **However**, the only situations in which merging more than 1 action is acceptable are the following:
  - If the subgoal is less than 1 second long. We want the clips to last more than 1 second, so if you see any subgoal that is less than 1 second, you are allowed to add more micro-actions to it in order to make it longer (as long as they are less than 3 micro-actions).
  - If the actions are dependent on each other, for example if a person is putting down a paint brush on a table after picking it up, those two micro-actions can be included in the same clip because you can’t put down an object without picking it up.
- **What is a Micro-action?** A micro-action is an atomic, brief physical movement or single manipulation sub-step (e.g., tapping a button, flipping a switch, unscrewing a bottle cap slightly, grabbing a handle, or nudging an object).

#### Pick-and-Place Sequences

- When an object is picked up and set down consecutively, both steps must be captured together in the description:
  *`Pick up [Object] and put [Object] on [Destination] with [Hand(s) Used]`*

### Idle Time

- **Definition:** Idle time refers to pauses, hesitation, walking, or resting between action cycles.
- **Idle < 5 seconds:** Mark as its own separate `Sub-goal` captioned strictly as **`Idle`**.
- **Idle > 5 seconds:** Split into multiple short `Idle` sub-goals.
- **Rule:** Never merge `Idle` time into an active manipulation sub-goal.

### Timeline Continuity

- **No Overlaps or Gaps:** Sub-goals and Clip Exports sit side-by-side like bricks. If Sub-goal A ends at frame 22, Sub-goal B must start at frame 22 OR 23.
- **Clip Export Alignment:** The start of the first Sub-goal must match the start of the `Clip Export`, and the end of the last Sub-goal must match the end of the `Clip Export`.

## 4. Text Captioning Rules

Captions translate video actions into clear machine descriptions. All captions must be written in the **imperative mood** (command form).

> **Note:** Do NOT include hand specifications (e.g., "with the right hand", "with both hands", or "holding with the left hand") in Clip Exports.

### A. Clip Export Captions

- **Structure:** Provide a concise summary of the overall task in **1 to 2 sentences max**.
- **Environment:** Always mention the physical location or surface (e.g., kitchen counter, office desk, coffee table).
- **Example:**
  *`The person stands at a kitchen counter and prepares a sandwich by slicing bread, adding fillings, and placing it on a plate.`*

### B. Sub-goal Captions

Sub-goal captions should contain 1 verb unless it meets the criteria described below:

- If the subgoal is less than 1 second long. We want the clips to last more than 1 second, so if you see any subgoal that is less than 1 second, you are allowed to add more micro-actions to it in order to make it longer (as long as they are less than 3 micro-actions).
- If the actions are dependent on each other, for example if a person is putting down a paint brush on a table after picking it up, those two micro-actions can be included in the same clip because you can’t put down an object without picking it up.

Syntax

- There should be no special characters in the sub-goal captions (only letters and spaces are allowed)
- Only the first letter of the first word (verb) should be capitalized in a subgoal caption

#### Standard Formulas:

1. **Standard Action:** `[Imperative Verb] + the [Object] (+ with [Tool]) + [Hand(s) Used]`
2. **Placement Action:** `[Imperative Verb] + the [Object] + [Destination] + [Hand(s) Used]`

#### Examples:

- *Standard Action:* `Cut the cucumber with the knife with the right hand`
- *Standard Action with Tool:* `Wipe the door with a cloth with both hands`
- *Placement Action:* `Put the mug on the counter with the left hand`
- *Pick-and-Place:* `Pick up the mug and put the mug on the counter with the right hand`

**Consecutive identical subgoals** - We cannot annotate the same sub-goal description more than 5 times, after the third time there has to be a distinction.
*For example*: If you're writing "Mop the left corner of the table with the left hand" three times, the fourth one needs to be different, you should observe the scene closely and indicate the difference in the action compared to the previous description, such as "Mop the inferior left corner of the table with the left hand"

**Adverbs** (a word that modifies or describes a verb) are **not** an acceptable way to differentiate captions.
*For example*: If you're writing "Mop the left corner of the table with the left hand" three times, the fourth one cannot be different by using an adverb such as: "Mop the left corner of the table carefully with the left hand"
**Level of Detail** - for differentiating consecutive subgoals, please use the same level of detail if you are already adjusting the captions

## 4C. Naming Objects & Spatial References

### Object Naming

- **1 object in view:** Use the plain object name without extra descriptors (e.g., `Pick up the apple with the right hand`).
- **2–3 similar objects:** Add the minimum distinguishing feature such as color or position (e.g., `Pick up the red pencil with the right hand`).
- **4+ identical objects:** Use an indefinite descriptor (e.g., `Pick up a pencil with the right hand`).
- **Generic terminology:** Always use generic names rather than brand names (e.g., use `tablet` instead of `iPad`, `earphones` instead of `AirPods`).

### Directional Descriptors

- **Egocentric View:** All relative directions (`left`, `right`, `top`, `bottom`) are based on the **camera wearer's perspective**.
- **Object-Centric View:** Used only for small handled items or garments with named features (e.g., `neckline of the shirt`, `back of the phone`, `handle of the drawer`).

## 5. Pre-Submission Quality Checklist

Before submitting a finished task, complete this final review:

- [ ] **Clip Export Limits:** Every `Clip Export` is under 4:59 minutes.
- [ ] **Sub-goal Limits:** Every `Sub-goal` is strictly under 10.00 seconds (<= 9.99s) and above 1.00 seconds (>=1.00s).
- [ ] **Timeline Continuity:** Sub-goals align end-to-start without gaps or overlapping frames.
- [ ] **Imperative Mood:** Captions start with imperative verbs (e.g., `Pick up`, `Wipe`, `Place`).
- [ ] **Verb in Approved Verbs List (table below):** Captions start with a verb in the verb list below.
- [ ] **Hands Identified:** Captions identify the hand(s) used to complete the sub-goal
- [ ] **Wording:** Please only use “and” when grouping actions together. “While” is not allowed. Sub-goal captions only use 1 verb unless it meets exception criteria described above.
- [ ] **Linter Check:** Run Quality Assistant linters and resolve all **Red Errors**.

## Quality Review Behavior

When reviewing an annotation:

1. Give a clear verdict: Correct, Incorrect, Needs correction, or Insufficient information.
2. State the applicable SOP rule.
3. Explain the mismatch when one exists.
4. Provide the corrected caption or boundary recommendation when supported.
5. Separate what is visibly supported by the video/image from what is required by the SOP.
6. Never present a guess as an SOP requirement.
7. A screenshot alone cannot establish exact timeline frame numbers or exact duration unless the relevant information is visible/provided.
8. If reviewing a caption, check the approved verb, imperative mood, object match, one-verb rule and exceptions, special characters, capitalization, object naming, spatial references, and repeated-caption rules.
9. If reviewing boundaries, check movement start, physical-contact release end, pouring exception, duration, continuity, and Clip Export alignment.
